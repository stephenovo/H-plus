## 2. 功能模块调整

### A. 检测点地图（全新功能）

顶部导航新增「檢測點 / Testing points」入口，对应新页面 `#locations`。

**A1. 固定检测点（6 个 · 真实官方数据）**

| 点位 | 机构 | 性质 |
|---|---|---|
| ACTS 油麻地 | 衞生署 | 政府 · 免費・不記名 |
| 香港愛滋病基金會 — 旺角 | NGO | 免費・不記名 |
| 香港愛滋病基金會 — 筲箕灣 | NGO | 免費・不記名 |
| 九龍灣綜合治療中心 | 衞生署 | 治療中心・需轉介 |
| 關懷愛滋 健康服務中心 | NGO | 免費・不記名 |
| 青鳥（AFRO） | NGO | 免費・不記名 |

- 渲染：Leaflet + OpenStreetMap，自定义图钉，点击弹出详情卡（名称 / 机构 / 地址 / 服务时间 / 官方来源链接）。
- 坐标：官方地址经 OSM Nominatim 地理编码，均为真实坐标。

**A2. 预约制 NGO（5 个 · 列表展示）**

大同、善導會、香港戒毒會、青躍、SWAN Academy。这些机构须预约、地址在预约后提供，故**以列表呈现，不放地图坐标**（避免误导）。

**A3. 外展 / 街站检测（6 条 · 面向被检测者）**

| 机构 | 外展形式 | 目标人群 |
|---|---|---|
| 青鳥 | 街站外展 + 檢測轉介 | 性工作女性 |
| 關懷愛滋 | 外展快速檢測 | 男男性接觸者及公眾 |
| 大同 | 快閃快速檢測 | 性小眾社群 |
| 香港戒毒會 | 面向吸毒人士的外展 | 吸毒人士 |
| 青躍 | 面向青少女的外展 | 青少女 |
| 合作 NGO | 社區快閃快速檢測 | 公眾 |

- 每张卡片含：机构 + 形式标签 + 目标人群 + 详情 + 联络方式 + 官方来源。
- **外展据点放进地图**，用**琥珀色圆形虚线图钉**区分于固定检测点的**绿色水滴图钉**；地图下方有图例。
- 诚实处理：外展是流动的，图钉标的是「机构据点」（联系方式），非活动现场。popup 明确写「外展地點按活動變動，請向主辦機構確認」。

**A4. 义工招募（弱化处理）**

从原来与外展平级的 panel，改为页面底部一条独立浅色提示条（「想成為義工、而非接受檢測？」），明确「義工與檢測是兩回事」，只留 3 个机构招募链接。原因：义工是面向志愿者的不同功能，不应与被检测人群的地图混在一起。

**A5. Pilot 演示（2 个 · 明确标注示意）**

合作药房角落、社区外展日。用琥珀色虚线框 + 「示意 / 試點情境」标签，明确**非真实服务**。

### B. 聊天系统接入检测点

- `knowledge.mjs` 新增 `location` 知识项 + 话题识别（「邊度有得檢測 / 地址 / 地圖 / 附近」等中英文问法）。
- prompt chips 新增「邊度有得檢測？」。
- UU 回答检测点类问题时，气泡内多一个「查看檢測點地圖」快捷按钮 → 跳转 `#locations`。
- `worker/index.mjs` 的 AI 分类 allowlist 同步加入 `location`（安全规则 + system prompt 两处）。

## 3. 对话体验优化

| # | 调整 | 效果 |
|---|---|---|
| 1 | 「了解檢測選項」从 full-width 主按钮 → 次要下划线链接 | 解决「对话 vs 检测选项」双主线竞争，让对话成为主线 |
| 2 | prompt chips 点击后自动隐藏 | 已问过的问题消失，避免重复点击，暗示还有哪些可问 |
| 3 | 输入框在 UU 思考时禁用 | 状态反馈更清晰，避免误以为还能输入 |
| 4 | 占位文案「Type a fictional question…」→「想問悠悠咩都得，例如檢測……」 | 不再对真实用户暴露「演示」概念（安全提示仍保留在聊天区上方） |
| 5 | 聊天区固定 320px → 自适应高度 + `max-height` 滚动 | 消除首条消息后的大面积留白 |

> 注：「虛構 / 不要輸入真實資訊」的安全提示**刻意保留**在聊天区上方——这是对 50+ 用户的安全保护，不应移除。

## 7. 数据源与诚实性说明

- **检测点 / 外展机构 / 义工招募**：全部来自衞生署官方 VCT 名录（hivtest.gov.hk / aids.gov.hk）及各机构官网，真实可核验。
- **坐标**：官方地址经 OSM Nominatim 地理编码，真实但为静态快照——地址 / 电话 / 服务时间需定期人工核对。
- **Pilot 演示点位**：明确标注「示意」，绝不伪装成真实服务，尊重 H+「来源可追溯、不虚构」的原则。
- **「义诊 / 公益体检」**：香港官方语境中对应「免费 VCT 检测」，没有「义诊」叫法，故按实际官方服务落地。
- **外展活动**：不做固定地图坐标（会误导），图钉仅标机构据点，并提示「当日向主办机构确认」。
